# IBUKI 資料索引ページ（合言葉つき）

台帳（`資料DB/台帳_志賀さん資料.csv`）とGoogleドライブのファイルIDを結合し、**分野別／日付順に並べ替えられる索引**を1枚のHTMLにする。ファイル名をクリックすると原本がドライブで開く。

作成 2026-09-07。守山さんの発案（HTMLで分野別・日付順・Driveリンクつき）。

## 作り直す

```bash
cd 資料索引ページ
python3 make_payload.py                 # Driveへ問い合わせて最新のIDを取る
#   --offline を付けると drive_ids.json を再利用（Driveを叩かない）
cd ibuki-index
IBUKI_PASS='合言葉' node build.js       # index.html を生成
git add index.html && git commit -m "…" && git push
```

`rclone` の remote は `gdrive_ibuki:`（**scope=drive.readonly**）。この索引はDriveを読むだけで、
並べ替え・改名・削除は権限そのもので封じてある（Drive不可侵原則）。

## ★合言葉を決めてから公開する

**最初のpushの前に合言葉を確定させること。**
一度pushすると、あとで合言葉を変えて force-push しても、**旧コミットはSHA指定でGitHub APIから引ける**
（`toku-board` で確認済み。本当に消すにはリポジトリの削除と作り直しが要る）。
「とりあえず公開して後で変える」ができない。

## 何を載せて、何を載せていないか

| | 件数 |
|---|---|
| 台帳の総件数 | 433（重複と旧版を含む） |
| 正本 | 279 |
| **ページに載せた** | **189** |
| ドライブに無い（別枠で名前だけ表示） | 37 |

載せていないもの:

- **同一sha256の重複**（別名コピー）。1本に畳んでいる
- **画像**（スライド素材の断片）
- **`やりとり`**（志賀さん↔守山さんのメール・Messenger履歴）
- **`検証・レビュー`**（Gemini生成文書の検証報告書などこちらの内部評価）
- **`知財`**（未出願クレームの具体値を含む。渡すかどうかは志賀さんの判断。9/7の束からも同じ理由で外している）

**★ただし「9/7の束」に入っているものは、分類に関わらず載せる。**
守山さんが既に「渡す」と判断済みだから。この例外が無いと、次の2件が落ちた（実測）:

| ファイル | 台帳の分類 |
|---|---|
| 菌叢…「MAX2870＋AD8302型 高周波RF測定回路の完全物理ピン配線図、および実装用BOM」 | `検証・レビュー` |
| 20260819打ち合わせメモAI志賀加筆 | `やりとり` |

ただし前者は回路の実装仕様であり、上杉さん・杉山さんの作業に直接効く。
**分類を見直すかどうかは結・守山さんの判断**（見直すなら `doctype_override.json` を直して日次バッチで再生成）。

## 印（バッジ）

| 印 | 意味 | 照合方法 |
|---|---|---|
| `一覧表 No.n` | 新宅さんの資料一覧46件に載っている（27件） | ファイル名の正規化＋類似度0.95。**一覧側の名称が要約されている行があるため取りこぼしうる** |
| `9/7の束` | 今朝お送りした35件に入っている（35件） | **sha256**。束は台帳から複製したものなので確実 |
| `他にN版` | 同じ系列の旧版がN本ある | 台帳の `series_key` |

★束の印を最初は名前の類似度で出していたが、「…提案」と「…提案2」という**別文書に印が付いた**（35→37件）。
sha256に替えて解消。**名前で照合してよいのは、名前しか手元に無いとき（一覧46件）だけ。**

## 検算（2026-09-07 実測・Chrome ヘッドレスをCDPで操作）

道具＝`/private/tmp/.../cdp_probe.js`（`--dump-dom` では非同期のcryptoを待てないのでCDPを使う。
また **`file://` は secure context ではなく `crypto.subtle` が無効**なので localhost で配信して測った）。

| 項目 | 結果 |
|---|---|
| 誤った合言葉 | 「合言葉が違います。」を表示し、開かない |
| 正しい合言葉 | 開く（189件・10分野） |
| Driveリンク | 189本すべて `https://drive.google.com/file/d/…/view` 形式・不正0・別タブ＋noopener |
| 新しい順／古い順 | どちらも並び順が正しい（2026-09-05 〜 2024-02-13） |
| 分野で絞る | 技術仕様＝80件 |
| 検索 | 「BOM」で2件・該当なしの語で空表示・消すと189件に戻る |
| 印 | 一覧表27件・9/7の束35件（束の実数と一致） |
| **平文の漏れ** | `index.html` に資料名・DriveIDは**0件**。入っているのは salt/iv/暗号文のみ |

暗号＝PBKDF2-SHA256 250,000回 → AES-256-GCM（WebCryptoで復号）。

## ★この合言葉で守れないもの

**Driveの共有設定そのもの。** リンクを開けるかどうかは、その人がそのファイルにアクセスできるかで決まる。
合言葉は「どんな資料が何件あるか」を隠すためのもので、原本のアクセス制御ではない。

**先方に最初の1件をクリックしてもらい、開けたかどうかを確認すること。**
9/6〜9/7に2〜3日を溶かした原因がまさにここ（`file:///E:/…` と、ドライブに無いファイル）。
索引が正しくても、権限が無ければ同じことが起きる。
